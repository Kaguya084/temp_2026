> 用纯原生代码构建一座数字化思政沙盘，直观映射从“制造大国”到“智造强国”的产业跃迁。

## 🌟 核心特性

- **🎭 原生级水波跃迁**：基于 CSS 变量与 View Transitions API，实现从“工业灰”到“赛博蓝”的平滑水波纹转场，拒绝生硬闪烁。
- **📊 手写数据滚动引擎**：拒绝第三方图表库，纯手写 `requestAnimationFrame` 缓动算法，实现宏观数据的丝滑跳动。
- **♾️ 无感双向画廊**：基于 Flex 与 `mask-image`，实现多行图片墙的横向无缝交错滚动，边缘物理渐隐。
- **🛡️ 防呆与容错机制**：动画期间全局状态锁定（`BUSY`），提供一键重置（`Reset`）功能，确保现场演示绝对不翻车。
- **💻 极简架构**：纯前端单文件，零外部依赖，断网环境下双击 `index.html` 即可运行。

## 🚀 使用流程与交互

| 交互动作 / 按钮 | 预期作用 |
| :--- | :--- |
| **点击 `AI 赋能`** | 触发水波转场，唤醒科技风主题，右侧数据开始动态滚动。 |
| **点击 `Reset`** | 中断当前状态，数据归零，UI 褪回初始工业风，可反复演示。 |
| **按 `F11` (键盘)** | 进入浏览器全屏模式，获得最佳的大屏看板体验。 |
| **点击顶部导航** | 平滑切换宏观背景、智造先锋、青年答卷等 5 个核心模块。 |

## 🔒 数据与安全

- **完全本地化**：本项目为纯前端单文件系统，无任何后端网络请求，所有交互与渲染均在浏览器本地完成。
- **理论底线**：页面展示的宏观数据（如智能工厂数量、机器人密度等）均引用于工信部、国家统计局及中国信通院等官方公开资料，无虚构数据。

## ⚠️ 已知限制

1. **浏览器兼容性**：`View Transitions API` 需要较新的 Chrome/Edge 浏览器支持。在旧版浏览器（如 Safari 旧版）中，系统会自动降级为瞬间切换，不影响核心数据展示。
2. **静态模拟**：目前系统内数据为静态宏观数据，尚未接入真实的工业互联网实时 API 接口。
